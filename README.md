✨ Features
Zero External Dependencies: No React, Vue, jQuery, Chart.js, or external CSS fonts/libraries.
Multiple Test Modes:
Timed Tests: 15s, 30s, 60s, and 120s modes.
Word Tests: 10, 25, 50, and 100 words.
Custom Modes: Set custom time limits or custom word goals.
Targeted Practice Arena:
Most common 100 English words.
Number row sequences and combinations.
Punctuation, symbols, and quotation marks.
Code syntax drill (keywords, brackets, operators).
Custom text input: paste your own essays, articles, or code.
Live Typing Engine & Metrics:
Animated, responsive caret positioning with line auto-scrolling.
Real-time gross WPM, net WPM, accuracy, and mistake counter.
Handling for backspaces, character overflows, and trailing errors.
Native Canvas Analytics & Charts:
Second-by-second WPM and error progression chart on test completion.
Historical speed progression graph on the Statistics view.
Synthesized Audio (Web Audio API):
Tactile mechanical key click sound effects generated directly via audio oscillators (no audio file downloads required).
Subtle sound cues for mistakes.
Personalized UI & Themes:
SaaS Dark (Default), Paper Light, and Cyberpunk Neon.
Font switching (Monospace vs. Clean Sans-Serif).
Data Portability:
Export test history and preferences to .json.
Import previous backups anytime.
